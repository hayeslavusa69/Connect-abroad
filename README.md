# Connect Abroad 🌍

A global social networking platform for connecting people across countries and cultures.

## Current milestone

This first build includes a responsive social-network interface with:

- Global feed
- Post composer
- Likes, comments and sharing controls
- Country discovery
- People-to-connect suggestions
- Search interface
- Messages and notifications navigation
- Mobile responsive layout

## Next milestones

1. Supabase authentication and user profiles
2. Real database-backed posts, comments and reactions
3. Friends/following system
4. Private and group messaging with realtime updates
5. Stories, groups and country/language discovery
6. Notifications, blocking and reporting
7. Media storage
8. Voice/video calls and live features

## Run locally

```bash
npm install
npm run dev
```
